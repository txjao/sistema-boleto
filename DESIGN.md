# Direção visual

A aplicação usa uma interface operacional clara e compacta, adequada ao uso prolongado em escritório. O site institucional orientou Manrope e um azul profundo; a composição foi criada para o sistema, com liberdade visual aprovada pelo usuário.

- Fundo cinza muito claro, superfícies brancas e azul `#023a51` para navegação e ações.
- Verde e vermelho são reservados a estados, sempre acompanhados de texto ou ícone.
- Raios de 6px para controles e 12 a 14px para painéis.
- Menu lateral fixo em desktop e sobreposto em telas menores.
- Tabelas semânticas e densas, com rolagem horizontal no mobile.
- Tailwind para classes pequenas; CSS Modules em `styles/` para layout, responsividade e estados complexos.
- Movimento restrito a feedback de carregamento, respeitando `prefers-reduced-motion`.
